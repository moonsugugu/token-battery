# 토큰배터리 (TokenBattery)

<img src="assets/icon.png" width="96" align="right" alt="토큰배터리 아이콘">

Claude와 Codex 토큰 사용 한도를 **배터리처럼 한눈에** 보여주는 Windows 데스크톱 위젯이에요. 리셋은 시각 또는 남은 시간으로 고를 수 있어요. 초소형 미니 모드의 주간 한도는 `2일`처럼 간단히 표시하고, 캐릭터·전체 모드에서는 `2일 남음 · 22:00 리셋` 또는 `1일 03시간 15분 남음`처럼 자세히 보여줘요. 하루 미만이면 시간·분으로 표시하고, 정확한 리셋 날짜는 마우스를 올려 확인할 수 있어요.
테마마다 전용으로 그린 배경과 서로 다른 캐릭터 듀오가 잔량에 따라 표정과 움직임을 바꿔요.

made by 문수네집

## 기능

- **모드 3가지**
  - 미니: 퍼센트와 리셋 시간만 보이는 초소형
  - 캐릭터: 캐릭터 두 명, 남은 한도, 5시간 리셋 표시와 자세한 주간 리셋
  - 전체: 오늘의 상태, 다음 회복, 구독 관리, BGM
- **디자인 10가지**: 사이버 · 엔진 코어 · 마스코트 · 아케이드(도트) · 글래스 · CRT · 인더스트리얼 · 가든 · 애니 · 에디토리얼. 테마마다 전용 히어로 아트와 서로 다른 캐릭터 듀오가 적용돼요.
- **캐릭터 반응 애니메이션**: 사용량에 따라 캐릭터 표정이 5단계로 바뀌고, 각 테마·캐릭터별 10프레임 시트로 배경은 고정한 채 눈 깜빡임과 작은 움직임을 보여줘요.
- **친구 관계와 진화**: 현재 테마에서 활성화한 Claude·Codex 친구에게 새 사용량이 쌓여요. 지인 → 친구 → 친밀 → 단짝 → 소울메이트로 성장하며, 장식·리본·별·날개 등 5단계 모습이 열려요. 10개 테마 × 2명 × 5단계, 총 100가지 모습이에요. 설정의 **친구 관계 · 디자인 보관함**에서 이전 모습도 다시 선택하거나 최신 모습을 자동으로 적용할 수 있어요.
- **사용량 알림**: 70 / 85 / 95%에 도달하면 윈도우 알림
- **작업 완료 알림**: 텔레그램·카카오 메시지 전송. 메신저 연결 뒤에도 Claude Code · Codex 설정에서 **완료 감지 연결**을 한 번 눌러야 해요. Codex는 재시작 후 `/hooks`에서 TokenBattery 훅을 검토·신뢰 처리해야 합니다.
- **구독 관리**: 여러 AI 구독의 결제일(D-day)과 월 합계, 실제 사용률 대비 비용 분석
- **코딩 BGM**: 분위기별 유튜브 긴 영상 검색
- **단축키**: 모드 전환(미니 → 캐릭터 → 전체 → 끄기)과 위젯 보이기/숨기기. 원하는 키로 바꿀 수 있어요.
- **크기 조절**: 아래쪽 양 모서리를 끌어서 조절하고, 두 번 누르면 원래 크기로 돌아가요.
- **5개 언어**: 한국어 · English · 日本語 · 简体中文 · Español

## 실행

```bash
npm install
npx electron .
```

설치파일을 만들려면 아래 명령을 실행하세요. 결과물은 `dist/TokenBattery Setup 1.1.0.exe`입니다.

```bash
npm run dist
```

Windows에서는 `실행.vbs`를 더블클릭하거나 바탕화면의 **TokenBattery** 바로가기를 실행하면 돼요.
Electron은 경로에 한글이 있거나 OneDrive 안에 있으면 화면이 뜨지 않아요. 그래서 `실행.vbs`는 앱을 `%LOCALAPPDATA%\ai-usage-widget`로 복사한 뒤 거기서 실행해요.

npm install 후 `node_modules/electron/dist/electron.exe`가 생기지 않으면 아래 명령으로 Electron 바이너리를 직접 설치하세요.

```bash
node node_modules/electron/install.js
```

## 사용량 데이터 출처

친구의 관계도는 실제 토큰 개수가 아닌 **자동 조회한 사용 한도의 증가분**으로 계산해요. 주간 한도 1%를 1 관계도로 적립하고, 지인 0 · 친구 15 · 친밀 70 · 단짝 200 · 소울메이트 약 429 관계도에서 해금해요. 소울메이트는 주간 한도를 꾸준히 사용하는 Pro 기준 약 30일(100% × 30/7주)을 목표로 설정한 추정치예요. 요금제·모델·사용 패턴에 따라 달성 기간은 달라져요. 주간 정보가 없을 때만 5시간 사용량을 5/168 비율로 환산하며 두 한도를 중복 적립하지 않아요.

관계도는 이 PC의 기존 앱 설정 파일(`%APPDATA%/ai-usage-widget/widget-store.json`)에 테마·친구별로 영구 저장해요. 홈서버를 사용하는 앱이 아니므로 서버 API나 새 DB는 추가하지 않아요. 앱이 실행 중이면 미니 모드·트레이에서도 성장하고, 종료·비활성화·테마 변경·연결 실패 후에는 다음 자동 조회를 시작점으로 삼아 지난 사용량을 소급 적립하지 않아요. 수동 입력은 관계도에 반영하지 않아요. 한도 리셋으로 관계도가 줄어들지 않고, 선택한 이전 모습으로도 계속 성장해요.

| 서비스 | 가져오는 곳 |
| --- | --- |
| Codex | `~/.codex/sessions/**.jsonl`의 `rate_limits` (로컬 로그, 네트워크 없음) |
| Claude | ① Claude Code 로그인 토큰 → ② 위젯 안에서 claude.ai 로그인 → ③ 직접 입력 |

Claude 사용량 API는 공식 공개 API가 아니라서 바뀔 수 있어요. 그때는 직접 입력으로 쓰면 돼요.

## 참고

- 한국 금융·키보드 보안 프로그램(AhnLab Safe Transaction, nProtect 등)이 깔린 PC에서는 Chromium 렌더러 샌드박스가 시작하자마자 멈춰요.
  - 위젯이 이걸 처음 감지하면 `%APPDATA%\ai-usage-widget\no-sandbox.flag`를 남기고 샌드박스 없이 다시 실행해요.
  - 화면 코드는 `contextIsolation`으로 Node 접근이 막혀 있어요.
- 문제가 생기면 `%APPDATA%\ai-usage-widget\widget.log`를 확인하세요.
- 아이콘 다시 만들기: `npx electron tools/make-icons.js` → `python tools/make-ico.py`
