# 토큰배터리 (TokenBattery)

<img src="assets/icon.png" width="96" align="right" alt="토큰배터리 아이콘">

Claude와 Codex 토큰 사용 한도를 **배터리처럼 한눈에** 보여주는 Windows·macOS 데스크톱 위젯이에요. 리셋은 시각 또는 남은 시간으로 고를 수 있어요. 초소형 미니 모드의 주간 한도는 `2일`처럼 간단히 표시하고, 캐릭터·전체 모드에서는 `2일 남음 · 22:00 리셋` 또는 `1일 03시간 15분 남음`처럼 자세히 보여줘요. 하루 미만이면 시간·분으로 표시하고, 정확한 리셋 날짜는 마우스를 올려 확인할 수 있어요.
테마마다 전용으로 그린 배경과 서로 다른 캐릭터 듀오가 잔량에 따라 표정과 움직임을 바꿔요.

made by 문수네집

## 기능

- **표시 모드**: Windows 4가지, macOS 3가지
  - 작업표시줄: 오른쪽 아래 시계·알림 영역 왼쪽에 서비스별 5시간·주간 잔량을 작게 표시. 둘을 켜면 두 줄, 하나만 켜면 한 줄이에요. 더블클릭으로 상세 보기, 오른쪽 클릭으로 모드를 고를 수 있어요.
  - 미니: 퍼센트와 리셋 시간만 보이는 초소형
  - 캐릭터: 캐릭터 두 명, 남은 한도, 5시간 리셋 표시와 자세한 주간 리셋
  - 전체: 오늘의 상태, 다음 회복, 구독 관리, BGM
- **디자인 10가지**: 사이버 · 엔진 코어 · 마스코트 · 아케이드(도트) · 글래스 · CRT · 인더스트리얼 · 가든 · 애니 · 에디토리얼. 테마마다 전용 히어로 아트와 서로 다른 캐릭터 듀오가 적용돼요.
- **설정에서 디자인 미리보기**: 디자인 선택 바로 위에 Claude·Codex 캐릭터를 나란히 보여줘요. 디자인을 바꾸면 현재 선택한 성장 단계와 실제 배터리 상태에 맞는 모습도 바로 바뀌어요.
- **캐릭터 반응 애니메이션**: 사용량에 따라 캐릭터 표정이 5단계로 바뀌고, 각 테마·캐릭터별 10프레임 시트로 배경은 고정한 채 눈 깜빡임과 작은 움직임을 보여줘요.
- **친구 관계와 진화**: 현재 테마에서 활성화한 Claude·Codex 친구에게 이 PC의 실제 처리 토큰이 쌓여요. 지인 → 친구 → 친밀 → 단짝 → 소울메이트로 성장하며 몸체·의상·날개·실루엣까지 크게 변해요. 10개 테마 × 2명 × 5단계 × 5가지 배터리 상태, 총 500가지 조합이에요. 설정의 **친구 관계 · 디자인 보관함**에서 이전 모습도 선택하고, 충전·보통·피곤·어지러움·잠든 모습을 미리 볼 수 있어요.
- **사용량 알림**: 70 / 85 / 95%에 도달하면 운영체제 알림을 표시해요.
- **앱 업데이트**: Windows 설치판은 시작 후 15초와 6시간마다 GitHub 정식 릴리스를 확인하고, 원하는 때 다운로드·설치할 수 있어요. macOS에서는 설정의 **릴리스 보기**에서 최신 DMG를 받아 응용 프로그램 폴더의 앱을 교체해요. 두 방식 모두 설정·로그인·친구 성장 기록을 유지해요.
- **작업 완료 알림**: 텔레그램·카카오 메시지 전송. 메신저 연결 뒤에도 Claude Code · Codex 설정에서 **완료 감지 연결**을 한 번 눌러야 해요. Codex는 재시작 후 `/hooks`에서 TokenBattery 훅을 검토·신뢰 처리해야 합니다.
- **구독 관리**: 여러 AI 구독의 결제일(D-day)과 월 합계, 실제 사용률 대비 비용 분석
- **코딩 BGM**: 분위기별 유튜브 긴 영상 검색
- **앱 사용법 튜토리얼**: 처음 켜면 단축키 → 표시 모드 → 사용량 연결 순서로 안내해요. 첫 화면에서 원하는 키를 지정하고, 이전·다음·건너뛰기로 이동할 수 있어요. 완료한 뒤에는 반복해서 뜨지 않으며, 설정의 **토큰배터리 사용법 → 다시 보기**에서 언제든 다시 열 수 있어요. 이번 업데이트 뒤 기존 사용자에게도 한 번 안내해요.
- **단축키**: 기본 **F7 = 위젯 숨기기/보이기**, **F8 = 모드 전환**. Windows는 작업표시줄 → 미니 → 캐릭터 → 전체, macOS는 미니 → 캐릭터 → 전체 순서로 전환해요. 튜토리얼 첫 화면에서 키 버튼을 눌러 원하는 키로 바꿀 수 있고, 나중에도 설정에서 변경할 수 있어요. 직접 지정한 단축키와 꺼 둔 키는 유지해요.
- **크기 조절**: 아래쪽 양 모서리를 끌어서 조절하고, 두 번 누르면 원래 크기로 돌아가요.
- **5개 언어**: 한국어 · English · 日本語 · 简体中文 · Español

## 실행과 설치

```bash
npm install
npx electron .
```

Windows 설치 파일은 `npm run dist`로 만들어요. macOS에서 Intel·Apple Silicon 공용 DMG와 ZIP을 만들려면 `npm run dist:mac`을 실행하세요.

```bash
npm run dist
```

```bash
npm run dist:mac
```

GitHub Releases에서 macOS용 `TokenBattery-<버전>-universal.dmg`를 내려받아 열고, TokenBattery를 **응용 프로그램** 폴더로 드래그하세요. 현재 배포 환경에 Apple 개발자 서명·공증 자격 증명이 없어 첫 실행 때 macOS 보안 확인이 나타날 수 있습니다. 이 경우 앱을 Control-클릭해 **열기**를 선택하세요. Windows 앱과 달리 macOS 앱은 수동으로 새 DMG를 설치해야 합니다.

## 새 버전 배포

변경을 `main`에 합치고 버전과 태그를 맞춰 push하면 GitHub Actions가 Windows 설치 파일과 Intel·Apple Silicon 공용 macOS DMG/ZIP을 각각 빌드해요. 두 빌드와 테스트가 모두 성공한 뒤 한 번에 정식 릴리스를 공개합니다.

1. `main`에서 `npm version patch` (또는 `minor`, `major`)로 버전과 태그를 올려요.
2. `git push origin main --follow-tags`를 실행해요.
3. GitHub Actions의 **Desktop release**가 Windows·macOS 양쪽에서 테스트와 패키징을 실행해요. 설치 파일과 체크섬을 모두 업로드한 후 릴리스를 공개해요. 버전 태그와 `package.json`이 다르면 배포를 중단해요.

기존 태그로 재시도하려면 Actions의 **Desktop release → Run workflow**에서 해당 태그를 입력해요. macOS 업데이트는 **릴리스 보기**에서 새 DMG를 내려받아 직접 설치합니다.

Windows 설치판은 `latest.yml`과 SHA-512 체크섬을 사용해 업데이트 파일을 확인해요. macOS 패키지는 SHA-256 체크섬을 제공하며, 코드 서명이 필요한 macOS 자동 업데이트는 현재 사용하지 않아요.

**v1.3.1 이하 사용자는 이번 버전 설치 파일을 한 번 직접 설치해야 해요.** 기존 프로그램에는 업데이트 확인 코드가 없으므로 새 릴리스를 올려도 알림을 보낼 수 없어요. v1.3.2부터는 이후 버전을 앱에서 확인하고 설치할 수 있어요.

Windows에서는 `실행.vbs`를 더블클릭하거나 바탕화면의 **TokenBattery** 바로가기를 실행하면 돼요. macOS에서는 응용 프로그램 폴더의 TokenBattery를 실행하세요.
Electron은 경로에 한글이 있거나 OneDrive 안에 있으면 화면이 뜨지 않아요. 그래서 `실행.vbs`는 앱을 `%LOCALAPPDATA%\ai-usage-widget`로 복사한 뒤 거기서 실행해요.

npm install 후 `node_modules/electron/dist/electron.exe`가 생기지 않으면 아래 명령으로 Electron 바이너리를 직접 설치하세요.

```bash
node node_modules/electron/install.js
```

## 사용량 데이터 출처

친구의 관계도는 **로컬 Codex·Claude Code 대화 로그의 실제 처리 토큰**으로 계산해요. 기본 기준은 지인 0 · 친구 60만 · 친밀 360만 · 단짝 1,200만 · 소울메이트 3,000만 토큰이에요. 하루 100만 처리 토큰으로 약 30일을 예상한 기본값이며, Pro의 고정 제공량을 뜻하지 않아요. 모델·캐시·사용 패턴에 따라 달성 기간이 달라지므로 설정에서 서비스별 소울메이트 목표를 100만 토큰 단위로 조정할 수 있어요.

Codex는 입력+출력 토큰을 합산해요. 캐시 입력과 추론 출력은 이미 해당 합계에 들어 있으므로 중복으로 더하지 않아요. Claude Code는 일반 입력+출력+캐시 읽기+캐시 생성 토큰을 합산해요. 반복 로그·스트리밍·복사된 세션은 중복 적립하지 않으며, 파일 끝 이후 추가되는 완성된 기록을 15초 간격으로 읽어요. ChatGPT·claude.ai 웹 사용이나 다른 기기의 기록은 적립되지 않아요. 로그가 없으면 보관함에 안내가 표시돼요.

관계도는 기존 앱 설정 파일에 저장해요. Windows 경로는 `%APPDATA%/ai-usage-widget/widget-store.json`, macOS 경로는 `~/Library/Application Support/ai-usage-widget/widget-store.json`이에요. 중복 방지 기록에는 해시·시각·토큰 합계만 저장하며 대화 본문은 저장하거나 전송하지 않아요. 홈서버를 사용하는 앱이 아니므로 서버 API나 새 DB는 추가하지 않아요. 앱이 실행 중이면 미니 모드·메뉴 막대에서도 성장하고, 종료·비활성화·테마 변경 이전의 사용량은 소급 적립하지 않아요. 수동으로 입력한 한도는 성장에 반영하지 않아요. 한도 리셋이나 목표 변경으로 해금된 모습이 사라지지 않으며 이전 모습으로도 계속 성장해요. v1.1.0에서 얻은 단계는 유지하되 과거 관계도를 실제 토큰으로 환산하지 않아요.

| 성장 기록 | 가져오는 곳 |
| --- | --- |
| Codex | `~/.codex/sessions/**.jsonl`의 `token_count`; `CODEX_HOME` 지원 |
| Claude Code | `~/.claude/projects/**.jsonl`의 assistant usage; `CLAUDE_CONFIG_DIR` 지원 |

아래 배터리 잔량 데이터는 성장 토큰과 별도로 표시해요.

| 서비스 | 가져오는 곳 |
| --- | --- |
| Codex | `~/.codex/sessions/**.jsonl`의 `rate_limits` (로컬 로그, 네트워크 없음) |
| Claude | ① Claude Code 로그인 토큰 → ② 위젯 안에서 claude.ai 로그인 → ③ 직접 입력 |

Claude 사용량 API는 공식 공개 API가 아니라서 바뀔 수 있어요. 그때는 직접 입력으로 쓰면 돼요.

## 참고

- 작업표시줄 모드는 Windows 작업표시줄 위에 작은 창을 겹쳐 표시해요. Explorer 내부를 수정하거나 주입하지 않아요. 화면 배율과 시계·알림 영역 위치를 읽어 배치하며, 작업표시줄이 자동으로 숨겨지거나 아래쪽이 아니면 오른쪽 아래 화면 안에 표시해요. 다른 모드로 돌아오면 기존 창 위치와 배율을 복원하고, 로그인·구독·친구 관계 정보는 기존 저장소를 계속 사용해요.
- 한국 금융·키보드 보안 프로그램(AhnLab Safe Transaction, nProtect 등)이 깔린 PC에서는 Chromium 렌더러 샌드박스가 시작하자마자 멈춰요.
  - 위젯이 이걸 처음 감지하면 `%APPDATA%\ai-usage-widget\no-sandbox.flag`를 남기고 샌드박스 없이 다시 실행해요.
  - 화면 코드는 `contextIsolation`으로 Node 접근이 막혀 있어요.
- 문제가 생기면 `%APPDATA%\ai-usage-widget\widget.log`를 확인하세요.
- 아이콘 다시 만들기: `npx electron tools/make-icons.js` → `python tools/make-ico.py`
